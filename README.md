# 🌍 Climate Conference SQL Data Analysis Project

## 📌 Project Overview  
This project analyzes a climate conference database using SQL to understand VIP participation, event engagement, and reservation patterns. The dataset includes information about VIP attendees, events, hotel bookings, and feedback relationships.

---

## 🛠️ Tools Used  
- SQL  
- Relational Database Design  
- Joins, Subqueries, Aggregations  

---

## 🧠 VIP & Event Analysis  
- Identified VIP presenters and attendees using self-joins  
- Analyzed relationships between VIPs through feedback connections  
- Filtered VIPs presenting events based on association type (e.g., education, government)

**Insight:** VIPs from education and government sectors play a key role in event participation and presentations.

---

## 🏨 Reservation & Attendance Analysis  
- Identified VIPs attending both welcome and dinner events  
- Analyzed hotel booking patterns for conference attendees  
- Explored RSVP behavior across different events  

**Insight:** Most VIPs who attend the welcome session also attend the dinner, indicating strong engagement levels.

---

## 📈 Event Participation Analysis  
- Calculated number of VIPs participating in each event  
- Identified most and least attended events  

**Insight:** Certain event topics attract significantly higher participation, reflecting attendee interest trends.

---

## 🔗 Data Relationships Explored  
- VIP-to-VIP relationships (feedback mapping)  
- VIP-to-Event participation  
- VIP-to-Hotel reservations  

---

## 🚀 Project Outcome  
This project demonstrates:
- Ability to design and query relational databases  
- Strong understanding of SQL joins and relationships  
- Experience analyzing event-based and customer-like datasets  
- Capability to extract meaningful insights from structured data  

---

## 💡 Key Learnings  
- Self-joins are useful for analyzing relationships within the same table  
- Combining multiple tables provides deeper business insights  
- Structured data can reveal patterns in event participation and engagement
